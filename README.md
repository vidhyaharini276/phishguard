# phishguard
Phishing detector
PhishGuard is a Dynamic Phishing Website Detection System that uses Machine Learning and Deep Learning techniques to identify phishing URLs and malicious websites before users access them. It analyzes URL and website-related features, classifies them as legitimate or phishing, and helps prevent users from being exposed to fraudulent websites. The system can be integrated as a pre-delivery security gateway for detecting suspicious URLs or messages before they reach a user's device.
